Appearance

Interface style
Browser chrome
Classic reproduces the Google Chrome 0.2/1.0 interface from 2009: a native window frame, menu bar, grey gradient tab strip, 23 px address bar with a page icon and a “go” arrow, and a status bar.
Modern is the dark, rounded chrome with a frameless window, vertical tab sidebar and the AI panel.
Show Home button
The house icon left of the address bar, as in Chrome 2009.
Show bookmarks bar
The bookmark strip under the toolbar. Toggle it live with Ctrl+Shift+B.
Restart required
The window frame, tab placement and menu bar change with the interface style, so a restart is needed for it to take effect.
Color mode
Light or dark
System follows your operating system and switches on its own when the OS does — no restart needed.
Light and Dark pin one mode regardless of the OS.

Performance & Memory

Memory Saver
Memory Inactivity Level
How long a background tab must stay idle before its renderer is released. A discarded tab stays in the tab strip and reloads when you click it. The MB figures quoted here are the per-tab estimate, not a measured benchmark.
Instant Memory Optimization
Discards every background tab's renderer and clears the HTTP cache. Tabs stay in the tab strip and reload when you click them; unsaved form text in them is lost.
Tabs currently sleeping
Background tabs whose renderer has been released. Activating one reloads it.
